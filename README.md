# Servlet Mini Project

# About the Project

The **Servlet Mini Project** is a Java web application developed during my MCA learning journey to understand the fundamentals of **Java Servlets**. The project demonstrates how servlets process client requests, generate responses, and manage user data using sessions and cookies.

Instead of focusing on a single application, this project contains multiple small examples that explain important servlet concepts through practical implementation.

# Objectives

* Learn Java Servlet programming
* Understand the request-response lifecycle
* Practice form handling using Servlets
* Explore Session and Cookie management
* Understand web application deployment on Apache Tomcat

# Features

*  Addition Calculator using Servlet
*  Login Request Processing
*  Cookie Handling
*  Session Management
*  Dynamic Response Generation
*  HTML Form Integration
*  Apache Tomcat Deployment

# Application Workflow

# Addition Module

* Accepts two numbers from the user.
* Sends the request to a servlet.
* Calculates the sum.
* Displays the result.

# Login Module

* Accepts user credentials.
* Processes the request using a servlet.
* Generates an appropriate response.

# Session Module

* Creates and manages user sessions.
* Demonstrates how data is preserved across multiple requests.

### Cookie Module

* Creates cookies.
* Reads stored cookie values.
* Demonstrates client-side data storage.

# How to Run

1. Clone this repository.
2. Import the project into Eclipse as a Dynamic Web Project.
3. Configure Apache Tomcat.
4. Deploy the project on the server.
5. Start Tomcat and open the application in your browser.
